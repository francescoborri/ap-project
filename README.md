# Advanced Programming project: F# Units of Measure

This repository contains the material for my final project of the course Advanced Programming (Master programme in Computer Science at the University of Pisa).

- The folder `docs` contains the main report exploring F# units of measure, a document explaining how the AI output has been validated and a document collecting the most relevant prompts used to gather information from different AI tools;
- The folder `examples` contains some relevant pieces of F# code examining the compiler behaviour in different scenarios, some of which causing the compiler to emit a type error, whereas in other the soundness is severely weakened.
